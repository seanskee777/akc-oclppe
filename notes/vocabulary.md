# Working vocabulary

Kept so the terms stay stable across sessions.

- **fragment** — one machine's piece of a file's identity
- **tether** — the link between a file and wherever it went
- **pedigree** — the origin chain, AKC-style
- **orphan** — a file with no attributable origin
- **executioner** — the recorded act of terminating a file
- **cluster map** — the visual of every file and where it travelled
- **spaghetti** — the same, said while annoyed
